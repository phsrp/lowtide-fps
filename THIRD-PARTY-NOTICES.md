# Third-party software

The Lowtide installer includes these, unmodified:

| Component | Used for | License |
| --- | --- | --- |
| [PresentMon](https://github.com/GameTechDev/PresentMon) 2.6.0 by Intel | Frame capture | MIT |
| [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) 0.9.6 (`LibreHardwareMonitorLib.dll` and its dependencies) | CPU / GPU sensors | MPL-2.0 (source at the link) |
| [Montserrat](https://github.com/JulietaUla/Montserrat) | Font | SIL Open Font License 1.1 |
| [Tabler Icons](https://tabler.io/icons) 3.49.0 | Icons | MIT |
| [Python](https://www.python.org/) 3.14, Tcl/Tk | Runtime | PSF License, Tcl/Tk License |
| [pystray](https://github.com/moses-palmer/pystray) | Tray icon | LGPL-3.0 |
| [Pillow](https://python-pillow.org/) | Images | MIT-CMU |
| [PyInstaller](https://pyinstaller.org/) bootloader | Exe | GPL-2.0 with bootloader exception |

Colours: [Rosé Pine](https://rosepinetheme.com/) Dawn (MIT).

The installer can also run the official [PawnIO](https://pawnio.eu/) setup 2.2.0 (unmodified, from [namazso/PawnIO.Setup](https://github.com/namazso/PawnIO.Setup); driver source at [namazso/PawnIO](https://github.com/namazso/PawnIO), GPL-2.0), which CPU temperatures need. It is only run if you tick it.
